## Featured Projects

### [Alfabetiza — Literacy Tracking Platform](https://github.com/nicolsam/Alfabetiza)

An independent product built for a teacher who needed a better way to organize and monitor students' reading levels. It is currently being validated with its first user and has a roadmap for broader academic-management capabilities.

- Built with **Next.js 16, React 19, TypeScript, Prisma and PostgreSQL**.
- Includes monthly assessments, historical progress, school-based RBAC, audit logs, transactional imports, internationalization and parent report links.
- Tested with **Vitest, Testing Library and Playwright** and supported by a bilingual developer handbook.
- [Live application](https://alfabetiza-app.vercel.app/) · [Repository](https://github.com/nicolsam/Alfabetiza)

### [5W2H Planner — Client Management System](https://github.com/nicolsam/5W2H-PLANNER)

A custom application delivered to a legal professional who needed visibility into demands, responsibilities, costs and performance metrics.

- Developed with **React, TypeScript, Laravel, MySQL and Docker**.
- Provides goals, action plans, steps, owners, departments, statuses and management dashboards.
- Translates a non-technical client's workflow into a structured full-stack product.

### [apLIS — Full-Stack Technical Assessment](https://github.com/nicolsam/apLIS-desenvolvedor-jr)

A medical-clinic management system created as a technical assessment for apLIS.

- Combines a **PHP 8.3 custom MVC API**, a **Node.js/Express API** and a **React 19** frontend.
- Includes Docker Compose infrastructure, MySQL, validation, internationalization, automated tests and soft-delete recovery.
- Documents the architecture and setup in both English and Portuguese.

### [PDF Protector — Internal Process Automation](https://github.com/nicolsam/pdf-protector)

A Python desktop application created to eliminate a repetitive PDF-protection workflow in my current administrative role.

- Reduced processing time from approximately **5 minutes to 10 seconds — about 30× faster**.
- Automates batch password protection, file matching, strong password generation and Excel report output.
- Includes a desktop interface with progress feedback, logs and error handling.

### [Contdomínio — Client Landing Page](https://github.com/ns-works/contdominio-landingpage)

A responsive institutional landing page delivered for a condominium-management and accounting company.

- Built with semantic HTML, JavaScript, SASS, Tailwind CSS and Splide.js.
- Includes responsive navigation, service sections, testimonials, partner carousels and mobile interactions.
- Focused on visual fidelity, usability, performance and translating business requirements into a production-ready interface.
